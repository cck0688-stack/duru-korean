# 『두루 한국어』 1권 — 오디오·워크시트 공개 규칙

정한 날: 2026-10-05 (오너)
방식: **유튜브(듣기·홍보) + 사이트(MP3·PDF 내려받기)**, 전체 공개, 로그인 없이.

---

## 0. 한 가지 원칙

**전자책·유튜브·사이트·파일 이름에서 트랙 번호를 글자까지 똑같이 씁니다.**
독자가 책에서 본 번호를 그대로 검색하면 어디서든 바로 찾을 수 있어야 합니다.
기준은 **전자책에 인쇄된 표기**입니다. 아래 예시의 번호 모양은 책 표기가 확정되면 그것으로 바꿉니다.

---

## 1. 번호 체계 (1권: 과 18개, 트랙 75개(확인 중), 워크시트 18개)

| 과 | 과 코드 | 트랙 | 트랙 표기(예시) | 워크시트 |
|---|---|---|---|---|
| START | `S` | 4 | S-1 ~ S-4 | 1 |
| Lesson 1~11 | `L01`~`L11` | 5씩 | 1-1 ~ 11-5 | 1씩 |
| Lesson 12 | `L12` | 4 | 12-1 ~ 12-4 | 1 |
| Lesson 13 | `L13` | 6 | 13-1 ~ 13-6 | 없음 |
| Lesson 14 | `L14` | 5 | 14-1 ~ 14-5 | 1 |
| Checkpoint 1~3 | `CP1`~`CP3` | 1씩 | CP1 ~ CP3 | 없음 |
| 전권 복습 | `R` | — | — | 4 (Review 1~4) |

워크시트 합계: 14 + 4 = 18.

**트랙 합계 확인 필요**: 위 과별 개수를 더하면 4 + 55 + 4 + 6 + 5 + 3 = **77**입니다.
오너가 알려 준 합계는 75입니다. 어느 과의 개수가 다른지 확정되면 이 표를 고칩니다.

책 전체에서 몇 번째 트랙인지(1~75)는 MP3 태그의 트랙 번호로만 씁니다.

---

## 2. 유튜브

### 영상
- **트랙 1개 = 영상 1개** (75개). 책에서 트랙 하나만 골라 반복해 듣기 쉽습니다.
- 화면: 고정 이미지 1장 (책 표지 색, 큰 트랙 번호, 과 제목, 「두루 한국어 1」).
  75개 영상 파일(이미지+오디오)은 제가 한꺼번에 만들어 드릴 수 있습니다.

### 제목
```
[Duru Korean 1] Track 7-2 · 낱말 | Lesson 7 <과 제목>
```
- 앞부분 `[Duru Korean 1] Track 7-2`는 모든 영상에서 같은 모양입니다 (검색·정렬용).
- 70자 안쪽 (휴대폰에서 잘리지 않게).

### 설명란 (첫 줄이 가장 중요합니다)
```
▶ 이 과의 MP3·워크시트: https://durukorean.com/b1/L7
📘 『두루 한국어 1』 Lesson 7 · Track 7-2

<트랙 내용 한 줄>

━━━━━━━━━━
1권 전체 오디오·워크시트: https://durukorean.com/book/1
© DURU KOREAN. 개인 학습용으로 자유롭게 들으실 수 있습니다.
```

### 재생목록
- **과마다 1개 (18개)**: `Duru Korean 1 · Lesson 7 <과 제목>`
  - 트랙 순서대로 넣습니다. **순서가 틀리면 사이트에서 다른 트랙이 재생됩니다** (사이트는 재생목록의 "몇 번째"로 트랙을 엽니다).
- **1권 전체 1개**: `Duru Korean 1 — All Audio`

### 설정
- 공개 상태: **공개**
- 시청자층: **"아동용이 아님"** (성인 학습자 대상. 아동용으로 두면 댓글·재생목록 저장 등이 막힙니다.)
- 카테고리: 교육 / 동영상 언어: 한국어
- 가능하면 자막에 대본(책의 대화문)을 올립니다. 검색과 청각 장애 학습자에게 도움이 됩니다.

### 사이트에 알려 줄 것
재생목록 **18개의 주소**만 보내 주시면 됩니다. 영상 75개의 주소는 필요 없습니다.

## 3. 사이트

### 주소
| 주소 | 내용 |
|---|---|
| `durukorean.com/book/1` | 1권 첫 화면: 과 목록, 1권 전체 오디오 받기 |
| `durukorean.com/book/1/lesson-7` | 과 페이지 |
| `durukorean.com/b1/L7` | 위 과 페이지로 가는 **짧은 주소** (전자책에 인쇄) |
| `durukorean.com/b1/S`, `/b1/CP1`, `/b1/R` | START, Checkpoint, 전권 복습 |

짧은 주소는 전자책보다 먼저 만들어 둡니다 (자료가 올라가기 전에는 "준비 중" 화면).

### 과 페이지
1. 과 제목 (책과 똑같이)
2. 유튜브 재생목록 플레이어 (`youtube-nocookie.com`, 개인정보 보호 모드)
3. 트랙 목록: 트랙마다 **[듣기]**(위 플레이어에서 그 트랙 재생) · **[MP3 받기]**
4. **[이 과 MP3 전체 받기]** (ZIP)
5. 워크시트: **[PDF 받기]** · **[인쇄]**
6. 이전 과 / 다음 과

### 파일 이름
```
MP3:       DuruKorean1_L07_T2.mp3        (START: DuruKorean1_S_T1.mp3, Checkpoint: DuruKorean1_CP1.mp3)
과 ZIP:    DuruKorean1_L07_Audio.zip
전체 ZIP:  DuruKorean1_All_Audio.zip
워크시트:   DuruKorean1_L07_Worksheet.pdf
복습:      DuruKorean1_Review_1.pdf
```

### MP3 태그 (휴대폰 음악 앱에서 순서대로 보이게)
| 태그 | 값 |
|---|---|
| 제목 | `7-2 낱말` (책 표기 + 내용) |
| 앨범 | `Duru Korean 1` |
| 아티스트 | `DURU KOREAN` |
| 트랙 번호 | 1부터 끝까지 (책 전체 순서) |

- 받은 파일이 이미 MP3면 **다시 압축하지 않고** 태그만 넣습니다 (다시 압축하면 음질이 떨어집니다).
- WAV 원본이면 128kbps(말소리 기준 충분)로 만듭니다.

## 4. 전자책에 넣을 것 (모든 판매처 공통)

- 앞부분 한 번: `오디오·워크시트 전체: durukorean.com/book/1` (+ 유튜브 채널 주소)
- 과 첫 페이지마다: `이 과의 오디오·워크시트: durukorean.com/b1/L7` (누르면 열리는 링크로)
- 오디오가 있는 자리마다: `🎧 Track 7-2` (위 번호 체계와 같은 표기)
- QR 코드는 선택입니다. 휴대폰으로 전자책을 읽는 독자는 찍을 수 없으니 **글로 쓴 짧은 주소가 기본**입니다.
- 판매처(아마존 킨들, 구글 플레이 북, 국내 서점)마다 외부 링크 규정이 조금씩 다르니 원고 등록 때 확인합니다. 무료 부록 자료로 가는 저자 사이트 링크는 보통 허용됩니다. 다른 판매처의 구매 링크는 넣지 않습니다.

## 5. 하는 순서

1. **오너**: 전자책의 트랙 표기와 트랙 제목 확정 → 파일을 아래 폴더 구조로 zip 전달
   ```
   Book1/START/  Book1/L01/ … Book1/L14/  Book1/CP1/ … Book1/CP3/  Book1/Review/
   ```
   (폴더 안 MP3 이름은 책 표기로: `7-2 낱말.mp3`)
2. **Claude**: 파일 이름·태그 정리, 유튜브용 영상(트랙 수만큼)과 제목·설명 목록(복사해 붙이면 되는 표) 만들기, 짧은 주소 먼저 열기
3. **오너**: 유튜브에 올리고 재생목록 18개 만들기 → 재생목록 주소 18개 전달
4. **Claude**: 사이트 과 페이지 18개 + 1권 첫 화면 만들기 (게시하지 않은 상태로)
5. **오너**: 견본(START)부터 확인·승인 → 공개
6. 전자책 최종본의 링크 확인

## 6. 비용

- 듣기는 유튜브라 사이트 전송량이 들지 않습니다.
- 내려받기만 Supabase 전송량을 씁니다 (한 달 누적). 1권 전체 오디오 1회 받기 ≈ 100~200MB.
- 매달 Supabase Usage를 확인하고, 많아지면 파일만 전송료 없는 저장소로 옮깁니다.
