# 2. 가장 중요한 규칙 — 반드시 2페이지

모든 워크시트는 반드시 **A4 세로형 2페이지**로 제작한다.

1페이지짜리도 안 되고, 3페이지 이상도 안 된다.

PDF 최종 결과: Page 1 / 2, Page 2 / 2 로 끝나야 한다.

---

# 3. 2페이지라고 해서 내용을 억지로 넣지 않는다

2페이지 제한을 맞추기 위해 글자를 지나치게 작게 만들거나 내용을 빽빽하게 넣지 않는다.

가장 중요한 원칙: **내용의 양을 페이지에 맞춘다. 페이지를 내용에 억지로 맞추지 않는다.**

내용이 너무 많으면:

1. 중복 설명 삭제
2. 예문 개수 축소
3. 중요도가 낮은 정보 삭제
4. 긴 영어 설명 압축
5. 문제 개수 적정화

순서로 조정한다.

절대로:

- 본문을 지나치게 작은 글씨로 만들지 않는다.
- 줄 간격을 과도하게 줄이지 않는다.
- 페이지 전체를 텍스트로 빽빽하게 채우지 않는다.

# 4. 기본 2페이지 구성

## PAGE 1 — LEARN

1페이지는 주로 새로운 내용을 배우는 페이지다.

권장 구조: HEADER → TITLE / Subtitle → WHAT THIS IS FOR →
1. Main concept / key expressions / reading material →
2. Vocabulary / key words / how to read →
3. Practical example / sample / sign / receipt / notice / dialogue → FOOTER

단, 주제에 따라 Section의 개수는 조정할 수 있다.

## PAGE 2 — USE & PRACTICE

2페이지는 이해한 내용을 실제로 사용하는 페이지다.

권장 구조: HEADER → (필요한 경우) 3. Tips / continuation / practical rule →
4 또는 5. YOUR TURN → ANSWERS → FOOTER

전체 흐름은 **Learn → Understand → Apply → Practice → Check** 가 되도록 한다.

# 5. 제목 영역

상단 브랜드 디자인은 기존 DURU KOREAN 스타일을 유지한다.

상단에는 DURU KOREAN logo, www.durukorean.com,
Level · Beginner / Beginner (high) / Intermediate (low) 등, 15 min / 20 min 을 배치한다.

그 아래에 큰 한국어 제목과 짧은 영어 subtitle을 배치한다.

제목은 짧고 실제 상황이 드러나도록 한다. 예:

- 카드 영수증 읽기: 얼마를, 어떻게 냈어요?
- 가게 영업시간 안내판 읽기: 지금 문 열었어요?
- 약 봉투 읽기: 언제, 몇 번, 며칠 먹어요?
- 날씨 앱 읽기: 우산이 필요해요? 마스크가 필요해요?

단순 문법 이름보다 **실생활 상황 중심 제목**을 우선한다.

# 6. WHAT THIS IS FOR

제목 아래에는 항상 짧은 학습목표 박스를 넣는다. 너무 길지 않게 한다.

학습자가 이 워크시트를 마친 후 무엇을 할 수 있게 되는지를 1~3문장으로 설명한다.

예: By the end, learners can identify the item, quantity, discount, payment amount,
and payment method on a Korean receipt.

WHAT THIS IS FOR에는 작은 브랜드 아이콘 정도는 사용할 수 있다.
그러나 다른 Section에서는 장식용 아이콘을 남발하지 않는다.

---

# 7. Section 디자인 통일

모든 주요 Section은 `[큰 원형 번호] SECTION TITLE ─────────` 구조로 통일한다.

예: ① KEY EXPRESSIONS / ② SHORT DIALOGUES / ③ TIPS / ④ MORE SPEAKING PRACTICE / ⑤ YOUR TURN

Section 번호는 붉은색 / coral 계열, 흰색 숫자, 큰 원형으로 한다.
Section 제목 오른쪽에는 얇은 가로선을 사용한다.

---

# 8. Section 내부에는 작은 번호를 사용

Section 안에 여러 항목이 있으면 ① ② ③ ④ ⑤ 형태의 작은 번호를 사용한다.

작은 번호는 연한 peach / coral 배경, 작은 원형, Section 왼쪽 정렬선에 맞춤으로 한다.

가장 중요한 규칙: **큰 Section 번호 아래에는 작은 번호부터 바로 시작한다.**
불필요한 아이콘 때문에 왼쪽 공간을 비워두지 않는다.

Section 1, Section 3, Section 4, Section 5 모두 같은 정렬 기준을 사용한다.

---

# 9. 이모티콘과 장식 그림 최소화

전구, 말풍선, 영수증 그림, 캐릭터, 사람 그림, 장식용 체크표시, 의미 없는 emoji는
기본적으로 사용하지 않는다. 정보를 설명하기 위해 반드시 필요한 경우에만 사용한다.

DURU KOREAN은 어린이 학습지가 아니라 **성인 외국인 대상 전문 한국어 워크북**처럼 보여야 한다.

---

# 10. 기본적으로 1단 구성

일반적인 설명, vocabulary, expressions, key words는 기본적으로 **1단 세로형 구성**으로 한다.

일반 학습내용을 억지로 좌우 2단으로 나누지 않는다.

2단 사용은 Answers, 매우 짧은 비교표, 서로 독립적인 두 개의 예제 정도만 허용한다.

---

# 11. 박스형 디자인

학습 요소는 단순 텍스트 나열보다 읽기 쉬운 박스 구조를 사용한다.

박스 스타일: white / very light cream background, soft sage / soft peach accent,
thin border, subtle rounded corners, 충분한 padding, 그림자 최소화.

각 카드 사이의 간격을 일정하게 한다. 박스 하나에 너무 많은 문장을 넣지 않는다.

---

# 12. 긴 읽기 지문

READ THIS와 같은 긴 한국어 지문은 반드시 1단, 충분한 좌우 여백, 적절한 line-height,
문단 구분, 양쪽 정렬을 적용한다.

```css
text-align: justify;
word-break: keep-all;
line-height: 1.65~1.75;
```

단, 짧은 영어 설명이나 문제 문장은 억지로 justify하지 않는다.

---

# 13. 표와 실제 생활 자료

receipt, shop-hours sign, medicine bag, weather app, apartment notice, kiosk, menu,
ticket, label, sign은 실제 문서처럼 보이도록 디자인한다.
그러나 사진처럼 복잡하게 만들지 않는다. 단순하고 선명한 정보 구조를 사용한다.

---

# 14. 표는 절대로 페이지 중간에서 자르지 않는다

제목 + 표 + 핵심 정보는 하나의 block으로 같은 페이지에 배치한다.

```css
break-inside: avoid;
page-break-inside: avoid;
```

---

# 15. Section 자체도 가능한 한 페이지에서 자르지 않는다

다음은 하나의 block으로 취급한다: Section title + 첫 항목, 표 제목 + 표,
안내판 제목 + 안내판, dialogue title + dialogue, YOUR TURN 제목 + 첫 문제,
ANSWERS 제목 + answer box.

Section 제목만 페이지 아래에 남고 내용이 다음 페이지로 넘어가지 않게 한다.

---

# 16. 실생활 예문

"한국에서 실제로 이런 상황이 생겼을 때 무엇을 읽고 무엇을 말해야 하는가?"를 중심으로 작성한다.
예문은 지나치게 많지 않게 한다. 한 개념당 보통 1개의 핵심 설명 + 1개의 실제 예문이면 충분하다.

---

# 17. 영어 설명

영어는 한국어 학습을 돕기 위한 보조수단이다. 영어 설명이 한국어보다 더 길어지지 않도록 한다.
짧고, 정확하고, 쉬운 단어를 사용한다. 학문적인 긴 문법 설명은 피한다.

---

# 18. YOUR TURN

Page 2에는 반드시 학습자가 직접 해결하는 YOUR TURN을 넣는다.
권장 문제 수 4~6문제, 대부분 5문제가 적절하다.

각 문제는 얇은 rounded rectangle 안에 배치한다. 작은 번호의 위치는 모두 동일하게 한다.
질문이 너무 길지 않도록 한다.

문제 유형: 정보 찾기, 상황 판단, 빈칸, 선택, 순서 배열, 실제 한국어로 대답하기를 적절히 섞는다.

---

# 19. ANSWERS

ANSWERS는 반드시 Page 2에, 가능한 한 페이지 하단에 배치한다.
별도의 연한 peach / pink box를 사용한다. 정답이 길면 Answers에서만 2단 배치를 허용한다.
문제 번호와 답 번호는 정확하게 일치해야 한다.

---

# 20. 가독성 기준

가독성을 디자인보다 우선한다.

- 본문 글씨가 작지 않은가
- 한 줄이 지나치게 길지 않은가
- line-height가 충분한가
- 한 박스 안에 글자가 너무 많지 않은가
- 빈 공간이 적절히 존재하는가
- Section 사이가 명확하게 분리되는가

권장: Body text 약 10.5~11.5pt 이상, Korean reading passage 약 10.5~11.5pt 이상,
Section title 약 14~17pt, Main title 약 21~26pt, line-height 약 1.45~1.7.
단, 실제 PDF 렌더링 결과를 기준으로 최종 조정한다.

---

# 21. 페이지를 꽉 채우지 않는다

흰 공간도 디자인의 일부다. Section 사이, 큰 제목 아래, 문제 사이, Answers 위에
적절한 breathing space를 남긴다. 단 지나치게 큰 빈 공간은 피한다.

---

# 22. 컬러 시스템

Primary: Dark Green / Accent: Brick Red / Coral / Secondary: Soft Sage Green /
Highlight: Soft Peach / Pale Pink / Background: White / Warm Off-white.
강한 색을 너무 많이 사용하지 않는다.

---

# 23. 정렬 시스템

Section 번호, Section title, 작은 번호, 본문 시작점, 카드 시작점, 표 시작점,
YOUR TURN 문제, Answer box를 정렬한다.
한 페이지 안에서 왼쪽 기준선이 여러 개 생기지 않도록 한다.

---

# 24. 공통 컴포넌트 사용

매일 새로운 파일마다 디자인을 새로 만들지 않는다. 공통 컴포넌트를 재사용하고
스타일은 공통 CSS / token으로 관리한다 (scripts/pdf/templates.mjs, scripts/pdf/sheet-v2.css).

WorksheetHeader, WorksheetTitle, PurposeBox, SectionHeader, NumberedCard, ReadingPassage,
VocabularyRow, DataTable, RealLifeDocument, DialogueBox, TipBox, PracticeQuestion,
AnswerBox, WorksheetFooter

현재 구현: sections[].steps (흐름 카드), sections[].items (번호 행 — VocabularyRow/NumberedCard),
sections[].box + note (TipBox), exercises[] {ask, items} (①② 소문항), task (YOUR TURN 안내 박스).

---

# 25. 콘텐츠 양 자동 조절

새로운 워크시트를 만들기 전에 먼저 콘텐츠의 총량을 계산한다.
2페이지에 비해 내용이 많은 경우 PDF부터 만들지 말고 먼저 내용을 축약한다.

우선순위: 필수 내용 → 실생활 활용 → 핵심 예문 → Vocabulary → 보조 설명.
중요도가 낮은 내용을 줄인다. 문제는 최소 4개, 보통 5개 정도 유지한다.

---

# 26. 2페이지 배치 사전 계획

코드를 작성하기 전에 PAGE 1과 PAGE 2에 무엇을 넣을지 먼저 계획하고,
각 Section의 예상 높이를 계산해 페이지 경계를 넘지 않는지 확인한다.
콘텐츠를 먼저 전부 만든 뒤 마지막에 억지로 2페이지에 끼워 넣지 않는다.

---

# 27. 자동 렌더링 검수

PDF 생성 후 반드시 PDF를 이미지로 렌더링하여 Page 1, Page 2를 확인한다.
코드상으로만 판단하지 않는다. 사람이 실제 PDF를 보는 것처럼 최종 이미지를 보고 확인한다.

# 29. 디자인 판단 기준

"예쁘게 꾸민 AI 자료"가 아니라 "한국어 교육 전문 출판사가 만든 워크북"처럼 보여야 한다.

1. 깔끔한가? 2. 읽기 쉬운가? 3. 정보 순서가 분명한가? 4. 한눈에 중요한 정보가 들어오는가?
5. 실제 외국인이 혼자 공부할 수 있는가? 6. 출력해도 보기 좋은가?
7. 이전 DURU KOREAN 자료와 같은 시리즈처럼 보이는가?

# 31. 가장 중요한 고정 원칙

- **RULE 1** 항상 정확히 2페이지.
- **RULE 2** 2페이지에 넣기 위해 글씨를 작게 만들지 말 것. 내용을 줄일 것.
- **RULE 3** 가독성이 디자인보다 중요하다.
- **RULE 4** 일반 설명은 1단을 기본으로 한다.
- **RULE 5** 큰 번호 → Section title → 작은 번호 → 내용 순서.
- **RULE 6** 불필요한 이모티콘과 장식은 제거한다.
- **RULE 7** 아이콘을 제거한 자리에 빈 공간을 남기지 않는다.
- **RULE 8** 하나의 표·영수증·공지문·안내판을 페이지 사이에서 자르지 않는다.
- **RULE 9** 긴 READ THIS 지문은 양쪽 정렬한다.
- **RULE 10** Page 2에는 반드시 YOUR TURN과 ANSWERS가 있어야 한다.
- **RULE 11** Answers는 가능한 한 마지막 하단에 위치한다.
- **RULE 12** 매일 제작되는 모든 자료가 동일한 DURU KOREAN 시리즈처럼 보여야 한다.
